# SmartGrade – Student Grade Management System

SmartGrade is a Java-based software project designed to manage student marks, calculate grades, and support quiz assessment.

## Features

- **Student Mark Management** – Manage student marks and academic records.
- **Grade Calculation** – Calculate student grades based on assessment marks.
- **Quiz Assessment** – Support quiz assessment functionality.

## Technologies Used

- Java
- MySQL
- Git and GitHub

## Testing and Documentation

- Prepared project documentation covering system requirements, functionality, and design specifications.
- Conducted functional testing of student mark management, grade calculation, and quiz assessment features.
- Documented test results and identified issues to verify that the system met its requirements.
